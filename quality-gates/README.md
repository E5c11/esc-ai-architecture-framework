# quality-gates/

Testing philosophy, coverage standards, and review checklists.

Quality gates apply across all platforms and architectures. Platform-specific
test tooling (e.g. Compose UI tests, MockMvc) is documented in the relevant
`platforms/` subdirectory and references these quality gates.

## What goes here

- Testing philosophy and principles
- Coverage thresholds and rationale
- What to test vs. what not to test
- Review checklists (pre-commit, pre-merge)
- Test naming conventions
