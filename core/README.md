# core/

Engineering principles that are platform and architecture agnostic.

A document belongs here if it is true regardless of language, framework, or
architectural style. If it names a technology, it belongs in `platforms/` instead.
If it only applies within a specific architecture, it belongs in `architectures/`.

## What goes here

- Dependency inversion
- Low coupling / high cohesion
- Separation of concerns
- Error propagation philosophy
- Naming philosophy
- Testing philosophy
- Documentation standards
